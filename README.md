# 🚀 Proyecto destacado

## MKSUD

### Plataforma para crear tiendas online listas para vender

**MKSUD** es una plataforma orientada a negocios que permite crear tiendas online personalizadas y preparadas para vender mediante **WhatsApp y Mercado Pago**.

El proyecto reúne desarrollo, implementación, experiencia de usuario, infraestructura e integración de servicios externos.

### ✨ Características principales

- 🏪 Arquitectura multi-tenant
- ⚡ Creación y onboarding de tiendas
- 🎨 Personalización visual
- 🛍️ Catálogo y gestión de productos
- 👤 Panel administrativo
- 💳 Integración con Mercado Pago
- 🔔 Webhooks y procesamiento de pagos
- 📅 Activación automática de planes
- 📱 Diseño responsive
- 🐳 Contenedores Docker
- 🐧 Infraestructura Linux
- ☁️ AWS + Cloudflare
- 🔐 Controles de seguridad y sesiones
- 🚀 Entorno preparado para producción

# ⚙️ Enfoque técnico

No me enfoco únicamente en que una aplicación funcione.

También considero:

**Usabilidad**  
Interfaces claras y adaptadas al usuario.

**Operación**  
Procesos simples y fáciles de mantener.

**Estabilidad**  
Testing, validación y resolución de incidentes.

**Infraestructura**  
Despliegues reproducibles y entornos controlados.

**Seguridad**  
Protección de sesiones, datos y configuraciones sensibles.

**Automatización**  
Uso de herramientas e IA para reducir tareas repetitivas y acelerar procesos.
